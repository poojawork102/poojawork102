**Focus:** Cybersecurity · FastAPI · Machine Learning · Docker

### 🔍 Cabinetsight-ai — Electrical Cabinet QC
**AI quality control tool**  
Compares cabinet photos against engineering drawings using computer vision. Detects components via YOLOv11, reads labels with EasyOCR, validates wire colours against IEC 60446. Closed-loop: FAIL → fix → re-check.  
**Focus:** Computer Vision · OpenCV · YOLOv11 · FastAPI  
[View Repository](https://github.com/poojawork102/Cabinetsight-ai)
